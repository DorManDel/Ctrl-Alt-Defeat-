# Rebrand migration notes

Previous prototype: `WinForgeCLI` / `winforge`.

New branding: **Ctrl+Alt+Defeat**; GitHub slug `CtrlAltDefeat`; CLI package `ctrl_alt_defeat`; one-click Windows launcher `CtrlAltDefeat.cmd`.

Existing `.winforge` database and `.winforge-capacity-*` directories intentionally remain supported to preserve scan history and safe cleanup of prior test data. Do not rename existing capacity test folders.

No GitHub repository has been created or published by this package. Change the repository slug if naming availability requires it. Make sure the project name and logo do not imply Microsoft affiliation.
